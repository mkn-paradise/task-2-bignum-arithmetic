# task-2-bignum-arithmetic

Реализация длинной арифметики (сложение, вычитание, умножение, целочисленное деление) для целых чисел, представленных в позиционной системе счисления с произвольным основанием M и максимальной разрядностью N (максимум N лимбов).

## Идея решения

*Ключевая идея:* в длинной арифметике числа представляются как массивы элементов, где каждый из элементов - цифра в выбранной системе счисления. В повседневной жизни человек использует 10ичную систему счисления, и элемент может содержать один из 10 вариантов: 0--9. В CPython реализована длинная арифметика, состоящая в том, что используется система счисления с основанием 2^30. Таким образом, каждый элемент a_i такой, что

```text
0 <= a_i <= 2^30 - 1
```
а само число A такое, что

```text
0 <= A <= 2^31 - 1
```

Операции выполняются не над числами, а над массивами цифр. Операции согласуются с простыми школьными алгоритмами сложения, вычитания, умножения и деления в столбик. 

Система счисления специально выбрана таким образом, чтобы операции над элементами массива использовали "обычную" арифметику: вычисления выполняются 64-битными инструкциями процессора.

При вводе 

```python
x = 1_152_921_504_606_846_977
```

python считывает x как строку "1152921504606846977", затем слева направо преобразовывает число x в число, представленное в виде лимбов по некоторому алгоритму. Таким образом, Python хранит число x в виде

```python
x = [1, 0, 1]
```
так как

```
1_152_921_504_606_846_977 = 1 + 0 * 2^30 + 1 * 2^60
```

При выводе числа оно преобразовывается из массива лимбов в десятиричную систему путем алгоритма перевода из системы счисления с основанием A в систему счисления с основанием B.


Число хранится как:

- знак (+1, -1 или 0 для самого нуля);
- список лимбов (цифр в системе счисления с основанием M), от младшего разряда к старшему. Каждый лимб — целое число в диапазоне [0, M).

*Ограничение N — максимально допустимое количество лимбов; если результат операции требует больше лимбов, чем N, бросается исключение BigNumOverflow.*

## Перевод строки в лимбы и обратно

- from_decimal_magnitude: цифры входной строки читаются слева направо, на каждом шаге происходит лимбы = лимбы * 10 + очередная_цифра, но сама операция * 10 и + цифра выполняется поразрядно, с переносом между лимбами (аналогично умножению «в столбик»).
- to_decimal_magnitude: обратная операция — число многократно делится на 10 (divmod_small), а получаемые остатки дают десятичные цифры результата от младшей к старшей.

## Арифметические операции

- Сложение/вычитание модулей — школьный алгоритм «в столбик» с переносом/займом (add_mag, sub_mag); знак результата определяется по обычным правилам знаков (реализовано в BigInt.__add__).

- Умножение модулей — квадратичный алгоритм «в столбик» (mul_mag).

- Целочисленное деление модулей — деление «в столбик» по лимбам, с подбором очередной цифры частного двоичным поиском на каждом шаге (divmod_mag). Деление выполняется с усечением к нулю (как в C++), а не к минус бесконечности (как в Python).

## Код разделён на два слоя:

- limbs.py — арифметика над «сырыми» модулями (списками лимбов, без знака), не зависящая от BigInt;

- bignum.py — класс BigInt, добавляющий поверх модулей знак и параметры системы счисления M, N.
